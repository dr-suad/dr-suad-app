# 📦 دليل نقل المشروع إلى كمبيوتر آخر

هذا الملف يشرح كيفية نقل مشروع **د. سعاد — عالم الرياضيات الممتع** إلى كمبيوتر جديد
(Linux / Windows / Mac) دون فقدان أي شيء.

---

## 1) متطلبات الكمبيوتر الجديد

| المتطلب | الإصدار المطلوب | للتحقق |
|---------|----------------|--------|
| **Node.js** | LTS (الإصدار طويل الأمد) — الإصدار 18 أو أحدث | `node -v` |
| **npm** | يأتي مع Node.js (الإصدار 8 أو أحدث) | `npm -v` |
| **Git** (اختياري) | لأي تحديث مستقبلي | `git --version` |

> 💡 يُنصح بتحميل Node.js LTS من: https://nodejs.org

---

## 2) خطوات التثبيت والتشغيل

1. انسخ مجلد المشروع بالكامل إلى الكمبيوتر الجديد
   (انظر `FILES-TO-MOVE.txt` لقائمة الملفات المهمة).
2. افتح الطرفية (Terminal) داخل مجلد المشروع.
3. نفّذ:

```bash
npm install
npm run dev
```

4. افتح المتصفح على:

```
http://localhost:5173/dr-suad-app/
```

> ⚠️ **مسار الموقع يتضمن `/dr-suad-app/`** — تجاهَل السطر 404، هذا صحيح بسبب
> إعداد `base` في `vite.config.js`.

---

## 3) ⛔ تحذيرات مهمة

- **لا تنسخ مجلد `node_modules`** — سيُعاد إنشاؤه تلقائياً بواسطة `npm install`.
  نسخه قد يسبب مشاكل تعارض أنظمة تشغيل (Linux↔Windows).
- **لا تنسخ مجلد `dist`** — هو ناتج البناء، يُعاد إنتاجه بـ `npm run build`.
- **انقل ملف `.env.local` يدوياً** — لا يُرفع إلى GitHub (محمي في `.gitignore`)
  لكنه **ضروري** لتشغيل المشروع (يحتوي مفاتيح Supabase).

---

## 4) ملف `.env.local` (أساسي)

يجب أن يحتوي على السطرين التاليين في جذر المشروع:

```
VITE_SUPABASE_URL=https://XXXX.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGci...
```

> 🔒 هذا الملف يحتوي مفاتيح خاصة — لا تشاركه علناً ولا ترفعه إلى GitHub.

---

## 5) خطوات ما بعد النقل (اختياري)

- لبناء نسخة إنتاجية: `npm run build`
- لمعاينة نسخة الإنتاج: `npm run preview`
- عند وجود مشكلة: احذف `node_modules` و `package-lock.json` ثم أعد `npm install`

---

## 6) النسخ الاحتياطي

شغّل السكريبت `backup.sh` لإنشاء نسخة مضغوطة (zip) من المشروع
بدون `node_modules` / `dist` / `.git`:

```bash
./backup.sh
```

سيُنشئ ملفاً باسم `dr-suad-app-backup-YYYYMMDD.zip` في المجلد الأب.
